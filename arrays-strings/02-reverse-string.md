
# Reverse a String

- **Platform:** LeetCode
- **Difficulty:** Easy
- **Language:** C
- **Topic:** Arrays and Strings

## Problem
Reverse the given character array or string.

## Approach
1. Find the length of the string.
2. Use two positions: one at the beginning and one at the end.
3. Swap the characters at these positions.
4. Move both positions toward the center.
5. Stop when they meet.

## Time Complexity
O(n)

## Space Complexity
O(1) auxiliary space

## Test Case

**Input:** `hello`

**Expected Output:** `olleh`
